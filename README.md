# 🚀 Projeto Portfólio - Base para Alunos Fullstack

Este é o ponto de partida para você criar o seu próprio portfólio profissional! O repositório contém a estrutura HTML básica e organizada para você customizar com as suas informações e estilizar com CSS.

---

## 🛠️ O que você precisa fazer?

Siga o passo a passo abaixo para começar a trabalhar no seu projeto:

### 1. Faça um Fork do Repositório
O primeiro passo é gerar uma cópia deste projeto na sua própria conta do GitHub.
* Clique no botão **"Fork"** no topo superior direito desta página.
* Escolha a sua conta para salvar o repositório.

### 2. Clone o SEU Repositório
Abra o terminal do seu computador e clone o repositório que agora está no seu perfil:
```bash
git clone https://github.com/leo-gomes-dev/portifolio-alunos.git
```
*(Lembre-se de trocar `SEU-USUARIO` pelo seu nome de usuário do GitHub).*

### 3. Desenvolva o seu Portfólio
Abra a pasta do projeto no VS Code e comece as alterações:
* **HTML (`index.html`):** Altere os textos com o seu nome, sua história na seção "Sobre Mim" e adicione seus projetos.
* **CSS (`/css/style.css`):** Use sua criatividade para criar o design, as cores e as fontes do seu portfólio.

---

## 📐 Estrutura do Arquivo HTML

O arquivo `index.html` foi estruturado usando tags semânticas para ajudar no SEO e na acessibilidade. Veja o que cada parte faz:

* **`<header>` (Cabeçalho):** Contém a sua logo (`LG.dev`), o menu de navegação e o botão de contato.
* **`<main>` (Conteúdo Principal):** Guarda as seções mais importantes do site:
  * `#inicio`: Seção de destaque (Hero) com o seu nome.
  * `#sobre`: Espaço para você contar quem você é e seus objetivos.
  * `#habilidades`: Lista com as tecnologias que você domina (ex: HTML, CSS, JavaScript, Node.js).
  * `#projetos`: Galeria para exibir os seus melhores trabalhos desenvolvidos.
* **`<footer>` (Rodapé):** Mensagem de direitos autorais e encerramento da página.

---

## 📋 Requisitos para Entrega

Ao finalizar o projeto, certifique-se de que:
1. O código HTML continua semântico e organizado.
2. O arquivo CSS está estilizando o layout de forma limpa.
3. Você fez o `git add`, `git commit` e `git push` para o seu repositório.
4. (Opcional) O site está publicado no GitHub Pages ou Vercel.
